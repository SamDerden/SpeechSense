# Статический аудит трансформеров

Источник: [Трансформеры.ipynb](../Трансформеры.ipynb), индексы ячеек с нуля. GPU не запускался.

| Ячейка | Техника | Результат проверки |
|---|---|---|
| 15,50 | Differential LR | model.bert не универсален; пересечение групп classifier bias и no_decay; часть параметров пропущена |
| 53 | Label smoothing | параметр реализован |
| 56 | Gradient clipping | параметр реализован |
| 60,63 | Custom head, CLS+mean | train_transformer не принимает custom_model_class/custom_model_kwargs |
| 74 | Mixup | mixup_alpha отсутствует в сигнатуре |
| 91 | FGM | use_fgm и fgm_epsilon отсутствуют в сигнатуре |
| 88 | Multi-task | проверить/реализовать MTDataset и MultiTaskModel |
| 85 | Distillation | пропущена; baseline нельзя выдавать за результат |
| 42 | Ансамбль | ошибочно один токенизатор для разных архитектур; нужны отдельные предсказания |
| 68 | Active learning | повторная инициализация вместо продолжения; выбор по батчам вместо глобального ранжирования |
| 71 | Curriculum | повторное создание списков внутри цикла; scheduler сбрасывается |
| 78 | Threshold tuning | повторное обучение не нужно при наличии вероятностей; оценка на test только после фиксации порогов |
| 81 | Seeds | хранение нескольких моделей на GPU, риск OOM |
| 32,34 | Аугментация | молчаливые исключения, повторные одинаковые переводы, возможные списки вместо строк |
| 15 | Обучение | нет resume, mixed precision, периодического сохранения; копия лучших весов остаётся на GPU |
| 11 | Split | 70/15/15 отличается от исторического split; нужен единый протокол и проверка пересечений |
