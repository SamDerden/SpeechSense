# SpeechSense

Сервис определения тональности русскоязычных голосовых и текстовых отзывов в Telegram. Три класса: 0 neutral, 1 positive, 2 negative. OOD — отдельный статус.

Статус: проектирование и перенос исследований; рабочий сервис пока не подтверждён.
